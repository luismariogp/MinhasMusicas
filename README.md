# 🎵 Minhas Músicas

Projeto desenvolvido durante meus estudos de Java e Programação Orientada a Objetos (POO).

## 📚 Sobre o projeto

O Minhas Músicas é uma aplicação desenvolvida para praticar conceitos de Programação Orientada a Objetos em Java.

O projeto trabalha com diferentes tipos de áudio, como músicas e podcasts, permitindo registrar informações e avaliações para identificar os conteúdos preferidos.

## 🛠️ Tecnologias utilizadas

- Java
- Programação Orientada a Objetos
- Git
- GitHub

## 📖 Conceitos praticados

Durante o desenvolvimento do projeto, pratiquei:

- Classes e objetos
- Encapsulamento
- Herança
- Polimorfismo
- Classes e métodos
- Métodos sobrescritos
- Modificadores de acesso
- Organização de pacotes

## 🎯 Objetivo

O objetivo deste projeto foi colocar em prática os conceitos de Programação Orientada a Objetos estudados durante minha formação em Java.

## 🚀 Como executar

1. Clone este repositório.
2. Abra o projeto em uma IDE compatível com Java.
3. Execute a classe `Principal`.
